# Emirates Critical Power

Marketing site for Emirates Critical Power LLC — UPS installation, maintenance, AMC and battery services in Dubai / UAE.

Built with [Astro](https://astro.build) for a static, fast site that can grow into more pages later.

## Commands

| Command           | Action                          |
| ----------------- | ------------------------------- |
| `npm install`     | Install dependencies            |
| `npm run dev`     | Start local dev server          |
| `npm run build`   | Build production site to `dist/`|
| `npm run preview` | Preview the production build    |

## Structure

- `src/pages/` — routes (add `about.astro`, `blog/...` here later)
- `src/components/` — page sections
- `src/data/` — shared content (FAQs, brands, contact)
- `src/layouts/` — HTML shell / SEO
- `public/` — static assets (`logo.png`, favicons)
